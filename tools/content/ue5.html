01목표

6인 팀의 PM으로 Unreal Engine 5 기반 멀티플레이 사회적 추론 게임을 만들었습니다. 기한 안에 핵심 플레이 루프와 멀티플레이 흐름을 시연까지 완성하는 것이 팀 목표였습니다. 맵 디자인·UI·레벨 스트리밍 작업도 함께 맡았습니다.

비기능 요구사항

  • 와이어프레임개발 전에 9화면을 그려 화면 흐름과 전환 조건을 맞췄고, 개발 중 바뀐 부분은 다시 반영했습니다.
  • 요구사항 명세서우선순위 기준은 P1(없으면 게임 진행 불가)·P2(핵심 경험에 직접 영향)·P3(품질·운영 편의)로 두었고 항목마다 수용 기준도 붙였습니다.
  • Jira · 스크럼에픽·스토리·이슈는 Jira로 관리하고 진행 상황과 병목은 스크럼에서 공유했습니다.
  • Git 훅브랜치 이름에서 뽑은 Jira 이슈 키가 커밋 메시지에 붙는 Git 훅을 직접 만들었습니다.

03서버가 늦어졌을 때

개발 중 EC2 서버 지급이 늦어지면서 팀 전체가 서버 디버깅에 묶였습니다. 저는 클라이언트에서 먼저 만들 수 있는 기능과 서버 연동 작업을 나눠 작업 순서를 다시 짰습니다. 서버가 준비된 뒤에는 전체 로직 검증으로 흐름을 넘겼고 매일 각자 할 일을 정리해 팀이 MVP에 집중하게 했습니다.

04결과

팀은 기한 안에 핵심 루프와 멀티플레이 흐름을 구현해 최종 시연을 마쳤습니다.
